PORTFOLIO WEBSITE — Don Emmanuel Aluquin

1. Open index.html in a browser to preview the site.
2. Put your real CV PDF in this folder and name it: CV.pdf
   The "View CV" buttons already point to that file.
3. To add artwork:
   - Open index.html in a code editor.
   - Find the `const projects = [...]` section.
   - Duplicate one object and change title, category, and image path.
   - Put the new image inside the assets folder.
4. The gallery supports category filters and a full-size image modal.
5. Replace the sample email/social links near the bottom with your real links.

The visual theme uses a light-blue / white palette and is responsive for desktop and mobile.
